# 50. Best Time to Buy and Sell Stock

## Problem Statement

Given n daily stock prices, determine the maximum profit obtainable by buying once and selling once on a later day. If no positive profit is possible, return 0. The buy and sell days must be different, and buying must occur before selling.

## Input Format

The input contains `n` followed by exactly `n` integer prices.

## Output Format

Print the maximum achievable profit as an integer.

## Constraints

- 1 <= n <= 100000; 0 <= price[i] <= 1000000.

## Examples

Example 1
Input: 6 10 7 5 8 11 9
Output: 6

Example 2
Input: 5 5 4 3 2 1
Output: 0

Input starts with n followed by n prices.
